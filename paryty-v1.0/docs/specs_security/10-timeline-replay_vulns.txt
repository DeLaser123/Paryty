VULN-10-001 | Timeline SSE Endpoint Lacks Rate Limiting
Severity: MEDIUM
Pre-state:  SSE endpoint at /api/v1/timeline/replay
Post-state: Same
Evidence:   Code review of rest.go — timeline SSE handler. No per-tenant or
            per-IP rate limiting on stream connections.
Analysis:   SSE connections are long-lived and consume server resources (one
            goroutine per connection). An attacker could open hundreds of SSE
            connections to exhaust server resources.
Reproduce:  for i in $(seq 1 100); do curl -N http://localhost:8080/api/v1/timeline/replay & done
Mitigation: Add connection limits per tenant. Add rate limiting to the SSE endpoint.

VULN-10-002 | Bookmark Data in localStorage Without Validation
Severity: LOW
Pre-state:  Bookmarks were Zustand-only (lost on refresh)
Post-state: Bookmarks persisted to localStorage
Evidence:   timelineStore.ts: loadPersistedBookmarks() reads from localStorage
            and validates that bookmarks have id/timestamp/label strings.
Analysis:   Any JS code with access to the page (including via XSS) can read/write
            bookmarks in localStorage. This is inherent to localStorage and not a
            unique vulnerability. The validation prevents malformed data injection.
Reproduce:  localStorage.setItem('paryty:timeline:bookmarks', 'malicious json');
Mitigation: Current validation is sufficient. localStorage scope is per-origin.
