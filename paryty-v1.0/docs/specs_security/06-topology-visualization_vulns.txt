VULN-06-002 | WebGL Context Loss Handling May Leak GPU Resources
Severity: LOW
Pre-state:  PixiJS application created without explicit cleanup on context loss
Post-state: Same (unchanged — standardized handling not specified)
Evidence:   Code review: WebGLRenderer in PixiJS creates GPU resources that must
            be explicitly destroyed. The TopologyCanvas component's useEffect
            cleanup may not destroy all GPU resources.
Analysis:   If WebGL context is lost and restored, textures/geometries not properly
            recreated could cause rendering failures. No security impact, but
            availability concern for users.
Reproduce:  Open Chrome DevTools > Performance > simulate context loss while on
            /topology page. Observe if topology recovers correctly.
Mitigation: Ensure PixiJS renderer.destroy() is called in useEffect cleanup.
            Handle webglcontextlost/webglcontextrestored events.
